# FINN Field Guide

Three creative views are built into the same research workflow:

- Market City: original isometric company buildings, selectable with pointer or keyboard; a company passport contains dated prices, a real 22-session sparkline and a research action.
- Signal Map: a second spatial layout for selecting the same companies. Lines illustrate navigation, not correlation.
- Chart Desk: the previous featured-company chart remains available as the third view.

The scene shows up to eight valid watchlist companies. Decorative building heights are not market capitalisation, price, returns or portfolio weights. Data points preserve the source session date and currency. Scene motion has an explicit pause/resume control; OS reduced-motion settings disable ornamental animation. The view preference is stored in this browser.

Inspired by the spatial-navigation idea of https://antaragni.in/. All FINN scene artwork is generated by its own SVG/geometry components; no reference-site assets are shipped.

Checks: 26 automated tests, TypeScript and production compilation. City and map illustration renders were visually inspected. Native Chrome provided a real screenshot and accessibility state of the app, but controlled interaction/navigation has been intermittent; this is not a completed responsive-browser test pass.

Browser verification update: native Chrome interaction checks now pass for company selection, keyboard selection, scene pause, Signal Map and Chart Desk. A 390×844 responsive review led to a mobile illustration-fit and selector-size refinement. This supersedes the initial browser-access limitation above.
